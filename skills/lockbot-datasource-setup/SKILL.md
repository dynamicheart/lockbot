# Lockbot 数据源接入

将用户提供的机器范围、Lockbot 服务与资源配置转成可核验的数据源接入。复用已有监控优先；没有监控时可部署官方 Lockbot telemetry 包。资源申请、排队和指标采集独立，低利用率不代表空闲。

长期使用时安装仓库中整个 `skills/lockbot-datasource-setup/` 目录，包含 references、scripts 与 agents。若只收到此正文，先从同一批准仓库版本取得所需附件，或按公开文档手工准备配置；不要声称只有 SKILL.md 就已经安装了生成器。GitHub 是说明来源，不是用户的 Lockbot 服务地址。

## 先确认输入和现状

从用户提供的配置、已批准连接和实际版本读取：Lockbot canonical origin、目标 bot/UUID、节点与设备列表、当前数据源、允许采集的机器/部署主机、访问方式、网页 origin 和授权模式。只问无法核实的关键缺项。机器连接与资源数据源是两回事；不推断堡垒机支持端口转发或用户已授权配置免密。

先读 [接入与验证](references/setup.md)。如需部署或改服务，再读用户对应环境的部署/远程连接指引；不要把某位维护者的私有机器、代理、路径当成通用默认值。只读检查可先进行，用户已经授权的配置工作继续执行，不反复确认同一授权；申请新网络/身份范围等额外工作需明确其必要性。

核对服务实际支持的适配器。现有 Lockbot 仅实现 Prometheus 数据源；普通 HTTP JSON 与其他源可按新协议规划适配，但文档存在不代表旧版控制台已经支持。不要伪造 `type: json`、不存在的配置导入按钮或保存接口。

## 执行接入

1. **已有数据源**：读取经批准的只读示例，核实指标、单位、真实采样时间、节点标签和卡 UUID。测试不能扫描无关内网或猜机器/卡的对应关系。
2. **新采集服务**：从匹配版本的官方 Release 获取 telemetry 产出包及 checksum，确认平台/架构并校验。遵循部署说明检查 Linux/Python、驱动/SMI、端口、systemd 和已有服务。无需 MPI 或维护者私有脚本；多机 SSH 模式需要部署账号的已批准非交互访问，本机采集不需要 SSH。
3. 保持 SMI 默认每 300 秒错峰采集；用户刷新只读缓存，不反复执行 SMI。CPU 首次差分可能未知，失败/缺卡不能填零。别因无人占锁就查询未授权机器。
4. 明确每个 bot 节点/卡映射，NODE bot 同样核对其实际多卡。选择独立源认证或事先配置好的短期授权；不要选择自动授权后就宣称签名信任已建立。新增源不能覆盖已有源的签名密钥。
5. 只有在目标服务和用户权限明确时保存 bot 数据源。修改前读取并保留原配置，优先使用正常后台字段/验证流程，不用整份陈旧 bot JSON 覆盖其他字段。没有保存权限就交付配置给管理员，不尝试个人 Key 越权管理。

## 输出可复制结果

使用 `scripts/generate_config.py --input <私有输入.json> --output-dir <本机交付目录>` 生成现有 Prometheus 适配器配置、节点映射与字段填写表。输入格式见 reference；脚本只转换与校验本地配置，不探测网络、不部署、不签发 Key、不自动保存。它不能证明资源映射正确。

交付至少包括：

- 数据源类型/模板、真实 endpoint、访问模式、刷新/过期设置和每个节点/卡的对应关系。
- `utilization-config.json`（供程序维护/审核）、可复制的节点映射 JSON及控制台填写表。当前控制台没有整份数据源 JSON 导入，不指导用户把整份对象贴入节点映射。
- 已做的验证：来源版本/checksum、服务状态、认证拒绝/成功、各节点与卡覆盖、真实采样时间；标清未测试项。
- 明确状态：已生成、已验证、已保存、服务运行分别描述。源访问是 best effort；Agent HTTP 成功不代表浏览器 CORS/网络已验证，更不保证每个用户可达。

配置与机器目录交付到用户本机私有目录，不默认提交真实清单到 GitHub。可分享配置不包含签名密钥、源 token、Cookie 或 Lockbot Key；秘密仅引用批准的安全文件。SSH 私钥和登录密码不应发到聊天。保留既有资源授权、状态和用户会话；不要为了指标验收申请/释放真实资源。

## 权限与故障

资源网页、个人 Key、OP Key、后台 JWT 只发给对应 Lockbot，不发给数据源。指标使用源专用只读凭证；自动短期授权由源管理员显式建立信任，最长五分钟。不能把长期网页链接当成长期指标凭证，也不能声称普通 OP 已获得指标或详细备注权限。

无凭证/过期/越界须拒绝，源端 ACL 而非前端过滤决定范围。当前配套网关为节点级，不能宣称逐用户容器或逐卡隔离。CORS、HTTPS、本地网络权限和网络路由分别验证；不要使用 no-cors、关闭浏览器保护、公开内网服务或把 localhost 保存成全员可用 endpoint。

失败只影响指标展示；记录明确的未知/过期/错误，保留可回退配置，停止有问题的新服务而不影响锁与队列。
