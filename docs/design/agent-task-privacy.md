# Agent 任务信息隐私

公开任务信息只使用服务端预设分类。自由备注 `purpose`、Agent 名称 `agent_label`、授权备注和凭证标识仅本人、机器人管理员及已授权 OP 可见。群通知、只读网页和其他用户的 Agent 查询不返回这些字段。服务端裁剪返回值，前端隐藏不能替代访问控制。

新增可选字段 `task_category`，从 `/api/agent/context` 的 `usage_privacy.public_task_categories` 获取允许值；非法值在执行资源命令前返回 422。未填写不公开任务说明。群通知仅追加分类，不追加 Agent 名称或自由备注。数据库只增加可空分类列，旧记录保持原样且默认私密；原请求和 key 保持有效。不对旧备注做自动分类，不把自由文字自动发布。

例如：`operator_testing` → 算子测试；`communication_testing` → 通信库测试；`model_load_testing` → 模型压测。分类不允许拼接项目名或实验细节。私密备注仍应简洁，不记录密码、key 或完整提示词。它不是端到端加密的私人笔记：管理员和 OP 仍能读取，运维日志可能保留。

同一用户共用 key 的多个 Agent 共享本人权限，不能据此隔离彼此的备注。OP 访问仍须当前机器人专用 OP 凭证；个人 key 不能借此获得其他人的备注。历史已经发到群里的消息无法自动撤回。

旧版服务器未声明 `usage_privacy` 时，新 Skill 不发送私人字段；旧 Agent 的自由备注由升级后的服务器自动保护。升级增加一列，不修改原有字段；回退到旧代码会恢复旧的公开行为，因此遇到问题优先修复/保留隐私补丁，不能把数据库可回退等同于隐私策略可回退。
