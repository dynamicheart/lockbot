# Agent 任务信息隐私

公开任务说明仅使用服务端预设 `task_category`，从 `/api/agent/context.usage_privacy.public_task_categories` 发现。非法分类在执行前返回 422；未填不公开用途。旧请求和 key 仍有效，不自动将自由备注归类或发布。

| 读取者 | 本人私密用途 / Agent 名 | 他人私密详情 | 公开分类与资源状态 |
| --- | --- | --- | --- |
| 已验证个人 Agent key | 可以 | 不可以 | 可以，限当前 bot |
| 机器人管理员 / 普通后台账号 | 无 IM 身份映射，不能据同名推断 | 不可以 | 可以，限有权管理的 bot |
| 普通 bot OP key | 不提供本人身份 | 不可以 | 可以，保留已授权运维操作 |
| 超级管理员后台账号 | 可以 | 显式开启私密视图后可以，逐次读取留审计 | 可以 |
| 只读资源网页 | 不可以 | 不可以 | 可以，限查看码范围 |

`purpose`、`agent_label`、授权备注、凭证标识和未知未来任务字段属于私密任务信息。管理 state、OP snapshot、授权列表以及安全历史投影在服务端裁剪；隐藏前端文字不能替代访问控制。超级管理员按当前数据库角色判定，不能依赖缓存的旧角色。管理账号没有自动关联群聊身份，本人应使用已绑定个人 key。

管理权限、OP 释放权限、指标 `metrics:read` 和私密任务读取是不同能力。当前尚未实现可委派的 `task_private:read` 服务凭证，不允许普通 OP 或管理 JWT 伪造 scope 获权。管理接口默认返回公开投影，超级管理员也不例外。只有显式传入 `include_private=true` 且当前数据库角色仍为超级管理员时，才返回私密详情并逐次写审计；普通管理员传入该参数也不会获权。审计只记录读取入口和具名 bot（全局监控记为服务），不复制备注正文。既有 OP key 即使由超级管理员生成也仍是普通 bot 运维凭证。

私密 JSONL 文件仍保留详细内容，供经授权的运维处理。应用层的普通管理员不能下载原始任务历史或自由系统日志；旧日志正文无法可靠自动判断是否含私密内容，因此只返回时间、来源、固定命令词等安全摘要。共享历史函数 `public_event` 必须在搜索、分页和导出前调用，不能通过搜索命中情况泄露隐藏字段。原始日志仅超级管理员显式开启私密视图后可读，每次读取或下载独立留审计；未来字段默认不公开。

后台私密开关默认关闭，切换机器人或关闭开关会立即清空私密快照并使旧请求/下载失效。普通状态与监控轮询始终按公开视图查询，不产生 `task_private.read`；开启私密视图后暂停自动轮询，需要手动刷新。既有审计行保留，不通过隐藏或删除历史来降噪。

独立硬件数据源的授权不因本策略被取消：在其有效 `metrics:read` 范围内，仍可显示管理员批准的容器名、主机用户、程序摘要与逐卡指标。它们不是 Agent 私密任务备注，也不能把主机用户当作已验证的群聊身份。OP key 不能直接作为数据源凭证。

不新增数据库迁移，不擦除已有记录。普通 OP 的响应结构和资源维护操作保留，但私密用途字段不再返回，这是有意的权限收紧。旧代码回退可能恢复原有披露行为；优先保留隐私补丁而不是用数据库可回退证明隐私安全。

同一用户共用 key 的 Agent 共享本人权限，不能隔离彼此。服务器 root / 文件系统与备份操作权不属于应用 RBAC，不能承诺被本策略隔离。私密备注不是端到端加密笔记，仍不得放密码、key 或完整提示词。历史已经发到群里的消息不能自动撤回。

本策略是应用接口的 RBAC，不是加密隔离。不能防御宿主机 OS/root 权限、可读取部署文件的人，或已掌握平台签名凭据的人；例如如流机器人创建者原本持有 token/AES 等配置，本补丁不重设计既有平台身份信任边界。不得把密码、key、完整提示词等秘密放进私密备注，也不宣称绝对私密。
