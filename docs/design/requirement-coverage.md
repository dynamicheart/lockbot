## Acceptance evidence and limitations

Formal API/browser and remote test-service facts above were provided by the primary delivery record and cross-checked against merged PR metadata/current source. No private runtime files are copied into this document. Latest current-head CI is deliberately not hard-coded here: new commits invalidate older green runs.

A real 390px iframe CSS viewport check covered 16 cards without horizontal overflow. This is narrow-layout evidence, not a mobile-engine/touch acceptance. Broader NVIDIA and driver-lock/workload measurements are not satisfied by mocked data, a desktop screenshot or a successful first-host XML parse. Similarly, the server's privacy filters and version notices do not close the external-client compliance issue #24.
