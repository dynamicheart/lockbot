# LockBot 3.4.0

- Agent API v2 supports group binding, resource queries, locks, bookings, metrics authorization, and event streams.
- The group help links to the LockBot Skill ZIP. Skill 1.0.2 uses the Go `lb` client, queries across saved connections, and asks for a target when a lock or booking is ambiguous.
- Committed resource snapshots and per-credential admission limits protect queries and resource operations under polling load.

## Upgrade

Keep the existing data directory, instance identity, and encryption configuration. Existing v1 clients and keys remain supported. New v1 bindings are disabled by default. Use v2 for new bindings.

Set `PLATFORM_URL` to the deployment address so the Skill ZIP contains the correct service address. If you distribute `lb` internally, set `LB_RELEASE_MANIFEST_URL` to the HTTPS release manifest.
