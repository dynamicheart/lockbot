# LockBot 3.5.0

- Retire the personal resource dashboard. Old bookmarks show the retirement notice and old panel endpoints return HTTP 410. Use `lb` for personal resource queries and operations. Shared bot pages continue to show resources and queues.
- Record the source IP observed by the server in each bot's Agent operation history. The history supports V1 and V2 filtering and shows ten operations per page.
- Filter the service-wide Agent token table by API version and authorization status.

## Upgrade

Retain the existing service data volume and credentials. Existing Agent API connections continue to use their own authorization flows. The release does not mount the optional personal dashboard configuration or reuse its browser sessions.
