# LockBot 3.4.2

- Agent API v2 bindings describe bot-specific allocation and utilization rules. The API schema documents the rule fields for clients.
- Operators can configure overnight leases, utilization checks, and group notifications. Utilization checks can take queue demand, available resources, and overnight settings into account.
- Node information now groups registered login addresses, hardware, and supplemental attributes. Authorized exact resource reads can return registered login addresses.
- The v2 Skill documents resource queries, bot rules, and monitoring workflows.

## Upgrade

Back up the existing data volume before replacing the image. Check bot scheduling settings and data source status in Advanced Configuration after upgrading.
