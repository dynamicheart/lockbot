# LockBot 3.3.1

Patch release from v3.3.0.

- Agent API group notices report confirmed changes. Rejected requests keep their API reply and produce no group notice. Booking notices identify the booking queue. Release notices identify the resources actually affected.
- Device bots release the complete set of nodes in a whole-node batch. The command still releases only the caller's own holdings.
- Lock replies omit the personal workbench link. The configured Skill promotion and the explicit help entry remain available.

The patch uses the existing data volume and configuration. It introduces no schema migration or credential rotation.
