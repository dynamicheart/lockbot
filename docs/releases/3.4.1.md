# LockBot 3.4.1

- Agent API v1 ignores legacy Agent names, free-text purposes, and binding labels. Activity tracking keeps request counts without recording per-Agent names or associated IP addresses.
- Resource commands still support preset task categories. The standalone usage declaration endpoints have been retired.

## Upgrade

Existing v1 keys continue to support resource queries, locks, bookings, and releases. Use v2 to bind new groups. The patch requires no database schema changes when upgrading from v3.4.0. Historical records remain subject to their existing access controls and retention.
