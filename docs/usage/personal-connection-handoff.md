# 个人资源台的连接状态与 Agent 接入说明

在“我的连接”中，可以查看当前浏览器已经逐个确认的原生连接：资源群／机器人、本人平台身份、实际服务、Key 到期时间及恢复副本状态。相同姓名、相同用户 ID 字符串或外部报表不能代替另一个群的授权；尚未向当前浏览器授权的群不会自动出现。

点击“刷新 Key 状态”只重新验证现有绑定，不更换 Key、不延长到期时间，也不恢复已失效的权限。当前绑定过期、被撤销或迁移后，连接资料会被拒绝返回；仍有效的其他连接继续独立使用。恢复副本有三种情况：

| 状态 | 含义与处理 |
| --- | --- |
| 恢复副本可用 | 服务端目前有与该绑定匹配的加密副本；这里的列表不返回 Key。 |
| 旧 Key 尚无恢复副本 | 保留仍有效的本地 Key，由持有它的原 Agent 按 Skill 用原值回填一次并验证，不例行重置。 |
| 恢复副本暂不可读 | 保留有效原 Key，先检查服务和加密材料；不能据此认定原 Key 无效。 |

“复制接入说明”包含当前部署实际提供的 `lockbot-resource-agent` ZIP／Markdown 地址，以及精确的服务实例、bot 和已确认身份。将说明发给另一位 Agent 后，仍需单独私下提供 Key 或授权它读取本人私有凭据库。说明本身不含 Key，也不证明新 Agent 已获资源使用权限；它应先核对 `/api/agent/context`，保留其它服务／群的独立连接。

“发送给 Agent：复制恢复指引”在会话失效时也可使用。它提示 Agent 检查既有连接、保留有效 Key、区分恢复原值与重新绑定。过期或撤销的 Key 不能继续签发新授权。若全部授权副本确实丢失，使用现有群内撤销／重新绑定流程前，要由本人确认并说明共用该群 Key 的所有 Agent 都需要重新配置。状态刷新、恢复和查看不会自动执行重置。

本次能力只提供无 Key 的连接资料和接入说明；已有只读面板 Cookie、管理员登录及只读资源链接均不能据此查看 Key。显式 Key 查看需要独立的新鲜授权；多重确认的重置属于另外的独立能力，不能把其权限混入这里。

这些资料仅由原生身份提供方对本服务的确认绑定生成。外部资源报表的已授权群继续显示在资源查询和连接来源中，并标明“此来源仅支持资源查询，凭证请由原 Agent 管理”；本阶段不解密或转发外部来源的 Key。自定义身份提供方不会因为返回相同格式、名字或 URL 而获得原生连接／Key 权限，未提供能力时会显示管理暂不可用。旧面板 API 没有相应能力时，继续使用其原有只读界面。
