# 个人资源台的连接状态与 Agent 接入说明

“我的凭证”按已确认的绑定列出资源群和平台身份。打开该群的“Agent 接入说明”，再展开“连接详情”，可以查看服务地址、Key 到期时间和恢复状态。每个群的授权独立生效。

“刷新状态”重新验证当前浏览器的绑定。已经过期、撤销或迁移的绑定会失去对应的连接资料，其它有效绑定继续独立使用。Key 原值和到期时间由原绑定保持。恢复副本有三种情况。

| 状态 | 含义与处理 |
| --- | --- |
| 恢复副本可用 | 服务端目前有与该绑定匹配的加密副本；这里的列表不返回 Key。 |
| 旧 Key 尚无恢复副本 | 保留仍有效的本地 Key，由持有它的原 Agent 按 Skill 用原值回填一次并验证，不例行重置。 |
| 恢复副本暂不可读 | 保留有效原 Key，先检查服务和加密材料；不能据此认定原 Key 无效。 |

在某个群的“Agent 接入说明”弹窗中点“复制接入说明”，可以取得该群的 Skill 地址及服务、机器人和身份信息。表格上方的“复制全部状态”汇总当前列表中的群、Key 状态和各群接入说明。两种复制操作都省略 Key 原值和一次性票据。新的 Agent 需要单独获得该群的 Key 或本人私有凭据库授权，再通过 `/api/agent/context` 核对服务、身份和范围。

在“连接详情”或可用的“如何找回连接”区域，可以复制恢复指引。它提示 Agent 检查既有连接、保留有效 Key，并区分恢复原值与重新绑定。若全部授权副本丢失，由本人确认是否在群内撤销并重新绑定。共用该群 Key 的 Agent 随后需要重新配置。

对支持查看原值且有可用恢复副本的原生绑定，点“获取 Key 查看链接”，再点“复制查看请求”。已持有该连接有效原 Key 的 Agent 必须先核对本人身份和私密投递渠道，再用原 Key 向同一可信服务请求短期查看链接。页面会为其他连接显示“Key 暂不可查看”。只读浏览器授权、管理员登录、资源链接和登录票都没有签发查看链接的权限。

查看链接最多两分钟有效，且不会超过原绑定的到期时间。它放在 URL fragment，页面加载前清除地址栏内容，只向本人私下投递。当前浏览器还必须已经独立确认完全一致的服务、身份、bot 和绑定范围；链接不自动登录或添加另一位身份。页面先显示服务实例、资源群及身份，由本人再次点击“确认查看原 Key”才消耗单次票、临时显示服务端可恢复的原值；复制 Key 还需要独立点击。关闭、退出、切换范围、离开页面或到期时清除页面中的 Key；复制后的系统剪贴板由本人管理。

查看请求失败不会自动重试或换 Key，已消耗的票不能再次使用。旧 hash-only／损坏副本不能反推 Key，应保留有效本地原值，由原 Agent 按 Skill 回填或排障。过期、撤销、迁移、禁用或 Key 已发生变化时拒绝使用旧查看授权，也不会延长权限。

## 单独启用的多重确认重置

此能力默认关闭。管理员为原生身份提供方设置 `allow_credential_rotation: true` 并完成验收后，可以在“Agent 接入说明”的“连接详情”里点“请求重置 Key”。签发该请求需要原生绑定的有效原 Key。

重置真正使该身份在该群的旧 Key 作废：共用它的所有 Agent 都需要私下更新配置。先由持有有效原 Key 的 Agent 核对本人身份、私密投递渠道，获取专门的 `rotate_current_key` 短期链接；登录票和查看票不能转换为重置授权。链接最多两分钟有效，也不能超过原 Key 到期时间。过期、撤销、迁移或禁用的原 Key 必须拒绝，回到现有 IM 本人确认／绑定流程。

浏览器必须已有完全一致的本人绑定授权。页面预览服务、实例、具体资源群和身份，明确影响范围；本人必须输入完整资源群名，再勾选理解所有共用 Agent 将失效，最终点击确认。服务端保存独立的一次性意图，校验固定群名、第二确认、当前原绑定与 Key 后，才以事务和比较交换替换这一份 Key。新 Key 保留原到期时间，其他身份和群不受影响。

成功后新 Key 仅在本次无缓存响应中显示，请显式复制，逐个更新需要继续使用的 Agent。该绑定的旧面板授权和待用查看／重置票失效，其它独立授权继续可用；需要用新 Key 重新授权登录。关闭、退出、切换范围或到期会清除页面里的新 Key。

封装、事务或比较交换失败不会自动更换旧 Key。若提交后网络中断、页面超时或关闭，重置结果可能已经生效：不要再次提交或自动轮换，应由本人通过 IM 重新确认当前绑定，再按恢复指引处理；不能拿失效原 Key 为自己续权。

原生身份提供方和通过服务地址与实例验证的连接元数据适配器，都可以为已确认的绑定提供无秘密连接资料。只读报表可出现在资源查询中，仍需单独确认绑定才会出现对应的凭证条目。查看和重置原 Key 需要原生绑定的独立授权。具体信任条件见[连接元数据适配器](../design/connection-metadata-adapter.md)。

## Task details on held resources

The personal dashboard shows the recorded task category on an active holding.
Select the category to open the detailed note and Agent label when available.
These fields are available for the binding that registered the task on that
holding. External report sources may omit task details.
