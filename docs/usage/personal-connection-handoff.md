# 个人资源台的连接状态与 Agent 接入说明

在“我的凭证”中，可以查看当前浏览器已确认的 Lockbot 绑定，包括资源群、平台身份、服务地址、Key 到期时间和恢复副本状态。每个资源群分别授权，完成后才会出现在此页。

点击“刷新 Key 状态”只重新验证现有绑定，不更换 Key、不延长到期时间，也不恢复已失效的权限。当前绑定过期、被撤销或迁移后，连接资料会被拒绝返回；仍有效的其他连接继续独立使用。恢复副本有三种情况：

| 状态 | 含义与处理 |
| --- | --- |
| 恢复副本可用 | 服务端目前有与该绑定匹配的加密副本；这里的列表不返回 Key。 |
| 旧 Key 尚无恢复副本 | 保留仍有效的本地 Key，由持有它的原 Agent 按 Skill 用原值回填一次并验证，不例行重置。 |
| 恢复副本暂不可读 | 保留有效原 Key，先检查服务和加密材料；不能据此认定原 Key 无效。 |

“复制接入说明”包含当前部署实际提供的 `lockbot-resource-agent` ZIP／Markdown 地址，以及精确的服务实例、bot 和已确认身份。将说明发给另一位 Agent 后，仍需单独私下提供 Key 或授权它读取本人私有凭据库。说明本身不含 Key，也不证明新 Agent 已获资源使用权限；它应先核对 `/api/agent/context`，保留其它服务／群的独立连接。

“发送给 Agent：复制恢复指引”在会话失效时也可使用。它提示 Agent 检查既有连接、保留有效 Key、区分恢复原值与重新绑定。过期或撤销的 Key 不能继续签发新授权。若全部授权副本确实丢失，使用现有群内撤销／重新绑定流程前，要由本人确认并说明共用该群 Key 的所有 Agent 都需要重新配置。状态刷新、恢复和查看不会自动执行重置。

连接列表和接入说明始终不含 Key。需要查看原 Key 时，点击“查看 Key：复制单次授权请求给 Agent”，交给已持有该连接有效原 Key 的 Agent。Agent 必须先核对本人身份与私密投递渠道，再用原 Key 向同一可信服务请求专门的短期查看链接。已有只读面板 Cookie、管理员登录、只读资源链接或登录票不能签发／升级为查看票。

查看链接最多两分钟有效，且不会超过原绑定的到期时间。它放在 URL fragment，页面加载前清除地址栏内容，只向本人私下投递。当前浏览器还必须已经独立确认完全一致的服务、身份、bot 和绑定范围；链接不自动登录或添加另一位身份。页面先显示服务实例、资源群及身份，由本人再次点击“确认查看原 Key”才消耗单次票、临时显示服务端可恢复的原值；复制 Key 还需要独立点击。关闭、退出、切换范围、离开页面或到期时清除页面中的 Key；复制后的系统剪贴板由本人管理。

查看请求失败不会自动重试或换 Key，已消耗的票不能再次使用。旧 hash-only／损坏副本不能反推 Key，应保留有效本地原值，由原 Agent 按 Skill 回填或排障。过期、撤销、迁移、禁用或 Key 已发生变化时拒绝使用旧查看授权，也不会延长权限。

## 单独启用的多重确认重置

此能力默认关闭。只有管理员明确为原生身份提供方设置 `allow_credential_rotation: true` 并完成验收后，才会出现“重置 Key：复制专用授权请求给 Agent”。外部来源、状态刷新、恢复和查看都不能触发重置。

重置真正使该身份在该群的旧 Key 作废：共用它的所有 Agent 都需要私下更新配置。先由持有有效原 Key 的 Agent 核对本人身份、私密投递渠道，获取专门的 `rotate_current_key` 短期链接；登录票和查看票不能转换为重置授权。链接最多两分钟有效，也不能超过原 Key 到期时间。过期、撤销、迁移或禁用的原 Key 必须拒绝，回到现有 IM 本人确认／绑定流程。

浏览器必须已有完全一致的本人绑定授权。页面预览服务、实例、具体资源群和身份，明确影响范围；本人必须输入完整资源群名，再勾选理解所有共用 Agent 将失效，最终点击确认。服务端保存独立的一次性意图，校验固定群名、第二确认、当前原绑定与 Key 后，才以事务和比较交换替换这一份 Key。新 Key 保留原到期时间，其他身份和群不受影响。

成功后新 Key 仅在本次无缓存响应中显示，请显式复制，逐个更新需要继续使用的 Agent。该绑定的旧面板授权和待用查看／重置票失效，其它独立授权继续可用；需要用新 Key 重新授权登录。关闭、退出、切换范围或到期会清除页面里的新 Key。

封装、事务或比较交换失败不会自动更换旧 Key。若提交后网络中断、页面超时或关闭，重置结果可能已经生效：不要再次提交或自动轮换，应由本人通过 IM 重新确认当前绑定，再按恢复指引处理；不能拿失效原 Key 为自己续权。

这些资料仅由原生身份提供方对本服务的确认绑定生成。外部资源报表的已授权群继续显示在资源查询和连接来源中，并标明“此来源仅支持资源查询，凭证请由原 Agent 管理”；本阶段不解密或转发外部来源的 Key。自定义身份提供方不会因为返回相同格式、名字或 URL 而获得原生连接／Key 权限，未提供能力时会显示管理暂不可用。旧面板 API 没有相应能力时，继续使用其原有只读界面。
